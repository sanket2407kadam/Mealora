# 🍃 Mealora — Online Food Ordering System

Mealora is a modern online food ordering platform designed to make discovering food and ordering meals simple, convenient, and enjoyable.

Built with a premium **Forest & Sand** visual identity, Mealora aims to provide a smooth experience for customers, restaurant owners, and administrators.

## ✨ Features

- 🏠 **Modern Homepage** — Clean, premium, and responsive user interface.
- 🍽️ **Food Discovery** — Explore restaurants, food categories, and menu items.
- 🔍 **Search & Filter** — Find food according to your preferences.
- 🛒 **Shopping Cart** — Add and manage food items before checkout.
- 🔐 **Authentication** — Login and registration with secure authentication.
- 📦 **Order Management** — Place orders and track their status.
- 🏪 **Restaurant Dashboard** — Manage menus and customer orders.
- 🛡️ **Admin Panel** — Manage platform data and operations.
- 💳 **Online Payments** — Razorpay test-mode integration planned.
- 📱 **Responsive Design** — Designed for desktop, tablet, and mobile screens.

## 🚀 Getting Started

### Prerequisites

Install the following tools before running the project:

- Node.js and npm
- Java JDK 17 or newer
- PostgreSQL
- Git

### Frontend Setup

```bash
cd mealora-frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Backend Setup

The Spring Boot backend setup and database configuration will be documented as development progresses.

## 🔒 Security

- Keep database credentials and API secrets in environment variables.
- Never commit `.env` files containing secrets.
- Use Razorpay test credentials during development.
- Implement server-side payment verification before processing successful payments.
